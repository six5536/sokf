# @six5536/sokf-darwin-x64

This package contains the prebuilt `sokf` binary for `darwin-x64` (macOS,
Intel). It is an internal artefact of
[`sokf`](https://www.npmjs.com/package/sokf), which installs it automatically as
an optional dependency on a matching machine. Don't depend on it directly.
Install `sokf` instead.

[the sokf repository on GitHub](https://github.com/six5536/sokf).
