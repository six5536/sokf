# @six5536/sokf-darwin-arm64

This package contains the prebuilt `sokf` binary for `darwin-arm64` (macOS,
Apple silicon). It is an internal artefact of
[`@six5536/sokf`](https://www.npmjs.com/package/@six5536/sokf), which installs it automatically as
an optional dependency on a matching machine. Don't depend on it directly.
Install `@six5536/sokf` instead.

[sokf repository](https://github.com/six5536/sokf).
