# @six5536/sokf-win32-x64

This package holds the prebuilt `sokf` binary for Windows on `x64`
(`win32-x64`). It is an internal part of
[`sokf`](https://www.npmjs.com/package/sokf): npm installs it as an optional
dependency of `sokf` on a matching machine. Don't depend on this package
directly. Install `sokf` instead.

The Elastic License 2.0 covers this package. The source is in the
[sokf repository on GitHub](https://github.com/six5536/sokf).
