# @six5536/sokf-linux-x64

This package holds the prebuilt `sokf` binary for `linux-x64` (Linux on 64-bit
x86). It's an internal part of [`sokf`](https://www.npmjs.com/package/sokf),
which installs it automatically as an optional dependency on a matching machine.
Don't depend on this package directly. Install `sokf` instead.

The Elastic License 2.0 covers this package. For the source, see the
[sokf repository on GitHub](https://github.com/six5536/sokf).
