# schemas

- [Changelog Schema][sokf:schema-changelog] - A changelog records the changes to one specification, with one section for each version and the newest version first, and it is part of the specification that it records.
- [Grammar schema][sokf:schema-grammar] - The usage guide that sits beside the grammar file of the schema extension of SOKF (Superdev Open Knowledge Format) and shows how to write text that the grammar accepts.
- [SOKF format specification schema][sokf:schema-sokf-format-specification] - This schema shapes the one document that specifies the SOKF format. It requires each rule to be a criterion in the EARS (Easy Approach to Requirements Syntax) form, and it sets the title, the opening sentence, the sentence about how rules are stated, and the conformance sentence word for word.
- [SOKF schema specification schema][sokf:schema-sokf-schema-specification] - This schema governs the one document that specifies SOKF schemas: its rules are criteria in the EARS (Easy Approach to Requirements Syntax) form, and some of its sections hold fixed sentences.
- [SOKF Validation Specification Schema][sokf:schema-sokf-validation-specification] - This schema defines the one document that specifies validation in the Superdev Open Knowledge Format (SOKF). The document contains the rules, written as criteria in the EARS (Easy Approach to Requirements Syntax) form, and the fixed text that each document of this type repeats word for word.
