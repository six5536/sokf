# Code of conduct

This code of conduct sets out how to behave in the sokf project, which
behaviour is unacceptable, where the code applies, and how to report a problem.

- [Our pledge](#our-pledge)
- [Expected behaviour](#expected-behaviour)
- [Unacceptable behaviour](#unacceptable-behaviour)
- [Scope](#scope)
- [Reporting](#reporting)
- [Attribution](#attribution)

## Our pledge

We want sokf to be a project anyone can take part in. We expect everyone
involved, whether a contributor, a maintainer, or someone opening an issue, to
help keep it that way.

## Expected behaviour

Follow these rules when you take part in sokf:

- Be respectful. Disagree with the idea, not the person.
- Assume good faith. Most confusion is a missing explanation, not bad intent.
- Accept feedback gracefully, and give it kindly.
- Keep discussion focused on the work.

## Unacceptable behaviour

The following behaviour is unacceptable:

- Harassment, insults, or personal attacks
- Discriminatory comments about anyone's identity or background
- Publishing someone's private information without permission
- Sustained disruption of discussions

## Scope

This code of conduct applies in every project space: issues, pull requests,
discussions, and commit messages. The code of conduct also applies whenever
someone is representing the project elsewhere.

## Reporting

Report a problem privately to the maintainer, using the email address on the
[GitHub profile](https://github.com/six5536). If you would rather not use email,
open a [private security advisory](https://github.com/six5536/sokf/security)
instead.

The maintainer handles reports confidentially, and responds as quickly as they
reasonably can. The maintainer can warn, temporarily block, or permanently ban
anyone whose behaviour they judge to breach this policy.
